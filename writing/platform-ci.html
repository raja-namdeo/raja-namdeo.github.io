Zendesk · Jul 2025 – Apr 2026 · Platform engineering

CI the platform team actually ran

Platform engineering only counts if other people use the path you built. On the Zendesk platform team I owned CI/CD for that path, on GitHub Actions.

Two pieces sat in the pipeline next to the usual checks. One drafted pull-request descriptions. One reviewed code. The platform team adopted both. They were aids inside the existing review, not a replacement for it.

What shipped with the pipeline

  • GitHub Actions for build and release checks.
  • An AI PR-description generator used by the platform team.
  • A code reviewer the same team adopted.
  • React Testing Library and Cypress coverage, so a UI change had a check before release.

The evaluation harness for Admin Copilot followed the same idea: a model change should produce a report, not a surprise in a Suite account. CI is where that report belongs.
