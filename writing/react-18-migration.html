Persistent Systems · Jan 2023 – Jun 2025 · React

Moving a legacy frontend to React 18

The C++ library was one track at Persistent Systems. The other was system modernisation on the frontend: a legacy UI moved to React 18.

The upgrade was not a version bump in package.json. Concurrent rendering and hooks-based patterns replaced the older structure, and the bugs that only showed up in one browser came with that change.

What the migration included

  • React 18, including concurrent-rendering APIs.
  • Hooks-based components in place of the older patterns.
  • Cross-browser UI bugs found during the upgrade, then fixed so the new UI stayed stable.

The same kind of move showed up later at Zendesk, where Admin Center went to React inside unified navigation. The Persistent migration is the earlier version of that work, on a live frontend.
